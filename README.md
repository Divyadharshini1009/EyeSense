
# EyeSense AI

### Explainable and Uncertainty-Aware Eye-Tracking for Dyslexia-Related Reading Support

EyeSense AI is a research-based project exploring how artificial intelligence can analyse children's eye-movement patterns during reading to identify patterns associated with reading difficulties.

### Objectives
- Analyse eye-tracking data during reading.
- Explore AI-based reading-risk classification.
- Investigate explainable AI techniques.
- Explore uncertainty-aware predictions.
- Develop an accessible application for reading-support insights.

### Technology Stack
- Python
- Machine Learning / Deep Learning
- Data Analysis
- Explainable AI
- Streamlit (planned application interface)

### Project Status
Research and dataset exploration phase.

**Note:** This project is intended for research and reading-support purposes, not clinical diagnosis.
